# 📝 Journal App

A simple full-stack Journal App that allows users to create, read, update, and delete journal entries with a title and content. Built with a clean UI and a Spring Boot backend.

## 📌 Features

- Add a new journal entry (title + content)
- View all existing entries
- Edit an entry
- Delete an entry
- Responsive frontend interface

## 🧱 Tech Stack

### 🔧 Backend
- Java 17
- Spring Boot
- MongoDB (or your chosen DB)
- Maven

### 🎨 Frontend
- React (or specify if you're using Vite/CRA)
- Axios (for API requests)
